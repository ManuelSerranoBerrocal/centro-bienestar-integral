# Centro Bienestar Integral

Página web para centro de terapias: fisioterapia, masajes, acupuntura y bienestar.

## Instalación

```bash
npm install
```

## Configuración

Crear archivo `.env` con:
```
EMAIL_USER=tu_email@gmail.com
EMAIL_PASS=tu_app_password
PORT=3001
```

## Uso

```bash
npm start
```

## Deploy

Configurado para Netlify con formularios Formspree.
